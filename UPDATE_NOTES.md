# NashvilleHealth Insights Tool - V6 Update

This version focuses on making the tool simpler, more compact, and easier for nontechnical users.

## Interface

- Removed the About the Data navigation section.
- Added the nine supported communities directly to the landing page: Nashville, Austin, Raleigh, Durham, Charlotte, Denver, Atlanta, Fort Worth, and Dallas.
- Removed the "NashvilleHealth Data Storytelling" label from the hero.
- Reduced the landing-page height so the hero and question box can appear together on a typical laptop screen.
- Made Browse Topics more compact with four topic cards per row.
- Darkened the topic-area dropdown for stronger contrast.
- Moved chart titles and date notes outside the Plotly figure so long titles are never cut off.
- Reworded date notes so multi-year periods are clearly described as one estimate covering the full date range.

## Answers

- Main findings now name the measure instead of saying only "the value."
- Trend summaries explain that a range such as 2020-2022 is one estimate for the full period, not a separate value for each year.
- Comparison explanations and next-step ideas use shorter, more direct language.
- Action cards are more practical and understandable for community members.

## PDF Brief

- The PDF now includes every question and follow-up from the current conversation.
- Each exchange receives its own branded page with its finding, metrics, chart, explanation, next steps, and local resources.
- Main findings name the measure directly.
- Long explanations are shortened cleanly and no longer run off the page.
- Removed the bottom source/disclaimer paragraph; date information remains next to each chart.
- Added simple page numbers.

## Validation

- Eight automated tests pass.
- A three-page conversation brief was rendered and visually reviewed for clipping and overlap.
